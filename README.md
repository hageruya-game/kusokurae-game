# 圧力回廊

**「従うな。」** — スマホブラウザで遊べる、同調圧力体験ゲーム。

命令され、煽られ、圧をかけられる。
それでも自分の判断で選べるか。
短いけれど、終わったあとに何かが残る。

## 遊び方

- スマホブラウザでアクセスするだけ（インストール不要）
- タップ・スワイプで操作
- 全3ステージ（10〜15分で完走）

| ステージ | 内容 |
|---|---|
| Stage 1 — 命令 | 命令に従うか、逆らうか。法則を見抜け |
| Stage 2 — 斬撃 | スワイプで命令を斬れ。速度と判断力 |
| Stage 3 — 群衆 | 全部同じに見える。1つだけ違うものを見抜け |
